# theslowroad-site

The public web pages for The Slow Road, an iPhone app: the home page, the privacy policy and the support page.

- `index.html` is the home page.
- `privacy/index.html` is the privacy policy, served at `/privacy/`.
- `support/index.html` is the support page, served at `/support/`.
- `style.css` is the one stylesheet.
- `CNAME` names the custom domain, `theslowroad.app`, for GitHub Pages.
- `.nojekyll` tells GitHub Pages to serve the files as they are, with no build step.

The pages are plain HTML and CSS: no scripts, no cookies, no trackers or analytics, and no outside fonts. Keep them that way, because the privacy policy says so.
